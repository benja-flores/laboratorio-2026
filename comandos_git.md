## COMANDOS GIT ##

1) git config --list 
2) git config --global user.name "Nombre"
3) git config --global user.mail "ejemplo@mail.com"
4) git config --global core.editor "code --wait" 
5) git --version
6) cd (navegar)
7) mkdir (hacer carpeta)
8) cd .. (volver atras)
9) ls (mirar el contenido de una carpeta)
10) clear (limpiar comandos)
11) git init (inicializar repositorio)
12) git status (Verifica el estado del repositorio)
13) git add "nombre_del_archivo" (para agregar 1 archivo)
14) git add . (para agregar todos los archivos)
15) git commit -m "Mi Primer Commit"  (realizar un commit)
16) git log (Para ver los cambios hechos con fecha y usuario)
17) q (para salir)
18) git log --onelist (lo mismo que el log pero mas corto)
19) git branch -M main (crear rama principal)
20) git remote add origin "URL" (Conectar nuestro repositorio local con el de la nube)
21) git push -u origin main (Sube los cambios a la nube)
