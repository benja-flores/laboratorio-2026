Git es un sistema de control de versiones distribuido de código abierto, diseñado por Linus Torvalds en 2005 para gestionar cambios en archivos de código fuente con alta eficiencia y confiabilidad.  A diferencia de otros sistemas, Git permite que cada desarrollador tenga una copia completa del historial del proyecto en su máquina local, facilitando el trabajo sin conexión y la gestión rápida de ramas.

git commit -m "Mi Primer Commit"  (realizar un commit)
git init (inicializar repositorio)
git add . (para agregar todos los archivos)
git branch -M main (crear rama principal)
git push -u origin main (Sube los cambios a la nube)
